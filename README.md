# 무사랑 일일운세 V1

## 구성
- `index.html`: 설치 과정 없이 실행되는 단일 페이지 웹앱
- 양력 생년월일 입력
- Gregorian 날짜를 JDN으로 변환해 60갑자 일진 계산
- 일진의 천간·지지 상징과 생년월일을 시드로 한 규칙형 운세 문구 표시
- 모바일 반응형, 외부 API·서버·회원가입·유료 AI 호출 없음

## 로컬 실행
`index.html`을 크롬/엣지에서 열면 됩니다. 별도 설치가 필요 없습니다.

## 무료 배포 예시
1. GitHub에서 새 공개 저장소를 만듭니다.
2. `index.html`을 저장소 최상위에 올립니다.
3. 저장소 Settings → Pages → Deploy from a branch → `main` / `/ (root)`를 선택해 저장합니다.
4. 생성된 GitHub Pages 주소를 네이버카페 배너 링크로 연결합니다.
   (서비스 제공 조건은 바뀔 수 있으므로 배포 시 무료 플랜 조건을 확인하세요.)

## 중요한 계산 범위와 한계
- 일진은 기준일 2000-01-07을 갑자일로 두고 JDN 차이의 60일 순환으로 계산합니다.
- 양력 날짜만 지원합니다. 음력·윤달 변환, 절기 및 입춘 기준 연주 변경, 출생 시각·출생지, 월주·시주 및 전체 사주 해석은 구현하지 않았습니다.
- 띠 표시는 양력 연도만으로 계산한 참고값이며 입춘 경계를 적용하지 않습니다.
- 운세 문구와 점수는 재미와 자기성찰을 위한 규칙형 콘텐츠입니다. 검증된 개인 사주 감정이나 미래 예측이 아닙니다.
- 외부 API나 서버가 없어 생년월일을 전송하거나 저장하지 않습니다. 날짜는 방문자의 기기 현지 날짜를 사용합니다.
- 완전 무료 운영은 호스팅 업체의 현재 무료 플랜 및 이용 조건에 따릅니다.
